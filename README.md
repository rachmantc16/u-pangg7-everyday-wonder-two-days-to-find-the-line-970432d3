A tiny Node program that writes one sentence — at most 200 characters, with no trailing newline — about a small moment of wonder in everyday life: a blackout at dinner, a phone flashlight under a plastic water bottle, and a father who reaches up to swim in the ceiling. The program validates the sentence (length, single sentence, no stray whitespace) before writing it to `/output/entry.txt`, and its output is deterministic.

## Run it

```sh
node main.ts
```
